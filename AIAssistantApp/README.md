# AI Assistant Pro — Intelligence Edition 5.0

Android 16 / API 36 AI assistant built on the existing project.

## Core
- Gemini 3.8 Flash routing
- Adaptive local memory and feedback learning
- Knowledge Graph + temporal facts + decision ledger
- Evidence/confidence analysis
- Live web grounding for current questions
- Agent orchestration and Supreme Power multi-pass critique
- Safe reasoning summaries without exposing private chain-of-thought
- Multimodal file/image/PDF input through Gemini inline data
- Workspaces and persistent project context
- AI Watcher background monitoring + notifications
- Encrypted API key with Android Keystore
- Project/file export with `[file:path]` support
- Voice input/output

## Build
- compileSdk 36
- targetSdk 36
- Android Gradle Plugin 9.4.0
- Gradle 9.6.0
- AGP 9 built-in Kotlin disabled explicitly for stable Kotlin plugin compatibility
- Kotlin Gradle Plugin 2.4.10
- JDK 17

A GitHub Actions workflow is included at `.github/workflows/android-build.yml` and builds both debug APK and debug AAB.

## Important
No AI can honestly be guaranteed to be "the best on the market" from an app architecture alone. This edition is designed as a highly ambitious, extensible intelligence layer while keeping claims and confidence evidence-based.
